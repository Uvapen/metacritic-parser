# Metacritic Parser — тестовое задание (AI Automation Engineer)

Сервис раз в час собирает новые релизы Metacritic, хранит карточки игр,
пишет LLM-саммари отзывов критиков и игроков отдельно, подбирает похожие игры
из собственного каталога и находит летсплей с заключением по речи автора.

- **Сервис:** _подставьте URL деплоя_
- **Переписка с нейросетью:** `data/llm_logs.jsonl` (raw) + просмотр в UI: `/monitor` → «Вызовы LLM» → «диалог»
- **Стек:** FastAPI · SQLAlchemy 2 (async) · SQLite/Postgres · Groq (`openai/gpt-oss-120b` + запасная `openai/gpt-oss-20b` + `whisper-large-v3-turbo`) · APScheduler · Jinja2 · `curl_cffi` · YouTube Innertube

## Как это устроено

**Часовой прогон.** Первый прогон дня — карусель New Releases; остальные — SEE ALL пачками по 20 новых или требующих обновления (изменился Metascore, не доделано саммари). Карточка и саммари собираются сразу; похожие и летсплей ставятся в очередь и разбираются фоновым тиком по одной задаче, чтобы не смешивать нагрузку с прогоном.

**LLM-клиент.** Один общий пейсинг вызовов; ретраи 60/120/240 секунд с учётом `Retry-After`; суточный лимит 429 → переход на запасную модель из цепочки; 401/403 → hard-block до рестарта, чтобы не жечь квоту впустую. Каждый вызов пишется в `data/llm_logs.jsonl` (prompt, response, attempt, error, latency, `run_id`) и доступен в UI целиком.

**Похожие игры.** Очки: студия 3, узкий тег (`souls-like`, `metroidvania`) 2, обычный тег 1 (макс 3), жанр 0.5, платформа 0.5, аудитория 2 только бонусом; порог показа 3. Широкие ярлыки Metacritic (Action и т.п.) не учитываются. Пары, набравшие порог без уверенного признака, проверяются коротким LLM-вызовом; вердикт кешируется, пока не изменятся профили игр.

**Летсплей.** Защита от мусора: описание ролика вместо речи (`blurb`), обрезка сырых субтитров с эхом ASR, «субтитры»-копия описания — отбрасываются; живой речи нет → пустое саммари, задача уходит в повтор. Ролик без текста на карточку не попадает: остаётся заглушка «Подходящий летсплей не найден».

## Ключевые решения

- `curl_cffi` с TLS-имперсонацией Chrome — обход Cloudflare на Metacritic.
- Гидратация `__NUXT_DATA__` вместо хрупких CSS-селекторов: данные из структуры страницы, не из вёрстки.
- Fingerprint отзывов: LLM не вызывается, пока отзывы не изменились.
- Whisper через API Groq, а не локально: сервис живёт без GPU.
- Очередь обогащения (похожие/летсплеи) отделена от часового прогона и имеет свои кнопки дожима.
- Честные заглушки вместо имитации: нет текста ролика — нет видео и саммари, статус виден в мониторе.

## Тесты и CI

`python -m pytest` — unit-тесты пайплайна, похожих, YouTube/Whisper-логики; GitHub Actions гоняет их на каждый push. Разведочные `test_find_*.py` исключены из прогона как не-тесты.

## Известные ограничения

- UI и API без авторизации: для проверки по ссылке нормально..
- Бесплатный хостинг: редиплой стирает SQLite, sleep останавливает планировщик; для постоянной работы нужен том/VPS или внешний cron на `POST /api/pipeline/run`, а лучше Postgres.
- YouTube может отбить субтитры и скачивание антиботом — тогда летсплей остаётся заглушкой до повтора.
- Groq free-tier упирается в 429 при нескольких прогонах подряд; пейсинг и цепочка моделей смягчают, но не отменяют лимит.
